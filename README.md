# fanus.tr

fanus web stüdyosunun tanıtım sitesi: e-ticaret, kurumsal site, web otomasyonu ve QR menü.

- Next.js 16 (App Router) · Tailwind 4 · GSAP 3 (ScrollTrigger, SplitText, MotionPath) · Lenis · three.js
- `npm install` → `npm run dev` (http://localhost:3300)
- Üretim: `npm run build` · Docker: `Dockerfile` (standalone, port 3000)

Belgeler: `CLAUDE.md` (proje bağlamı), `docs/tasarim-dili.md`, `docs/acik-kararlar.md`, `docs/yayina-alma.md`.
